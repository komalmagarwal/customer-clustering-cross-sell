# Customer Clustering for Cross-Sell

An ML pipeline that segments financial exchange customers using 
clustering techniques to identify cross-sell opportunities across 
data monetization products.

Built for a securities exchange client, the model analysed 
transaction history and behavioural patterns to group customers — 
including hedge funds, proprietary traders, and HNWIs — and 
surface targeted product recommendations such as real-time market 
data feeds and premium analytics services.

## Approach
- Unsupervised clustering on transaction history and product usage
- Segment profiling to identify high-value cross-sell targets
- Recommendation mapping to data monetization product catalogue

**Stack:** Python · Scikit-learn · Pandas · Clustering (K-means, 
hierarchical) · Data visualisation
